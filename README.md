# Gold Oil - Inventory Management and E-Commerce System

## Project Description

Gold Oil is a web-based inventory management and e-commerce application developed using Django, Python, React, and JavaScript.

The application helps businesses manage products, inventory, customers, sales, invoices, deliveries, and financial reports.
It also provides an online shopping platform where customers can browse products, place orders, and make payments.

## Features

### Inventory Management
- Add, update, and manage products.
- Manage product categories and subcategories.
- Track inventory and stock information.
- Manage customer records.

### Sales Management
- Create and manage proforma invoices.
- Generate delivery notes and receipts.
- Manage sales transactions.
- Print business documents.

### E-Commerce
- Browse products.
- View product details.
- Add products to a shopping cart.
- Place orders and make payments.
- Track orders.

### Reports
- View business dashboards.
- Generate monthly reports.
- Generate yearly reports.
- Monitor business performance.

### User Management
- User registration and login.
- Profile management.
- Password recovery.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/angenguena/go-oil-application.git
```

### 2. Navigate to the project folder

```bash
cd gold-oil-application/Inventory
```

### 3. Create and activate a virtual environment

```bash
python -m venv venv
venv\Scripts\activate
```

### 4. Install dependencies

If `requirements.txt` is available:

```bash
pip install -r requirements.txt
```

Install frontend dependencies:

```bash
npm install
```

### 5. Configure the application

Configure the database connection, environment variables, and required API credentials.

### 6. Apply database migrations

```bash
python manage.py migrate
```

### 7. Run the application

```bash
python manage.py runserver
```

Open the application at:

http://127.0.0.1:8000/

Additional configuration or frontend build steps may be necessary depending on the development environment.
